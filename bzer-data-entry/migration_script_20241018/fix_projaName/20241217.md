Note : Must backup the database before executing the sql script.

Step 1: Execute the `proja_sotter_types.sql` script for update the proja-name.
Step 2: Execute the `BundleUploadScript.sql` script.
Step 3: Execute `load_proja_data.sql` script. To run this script follow the below steps:
1.  save the `csv` file in `C:/` drive (  `csv` file should contain only two column, `file name` and `proja name`  )
2.  Change and save the `csv` file name as `missing_proja`.
3. Run the `load_proja_data.sql` script in the command line.
```console
mysql -h [hostname] -u [username] -p --default-character-set=utf8mb4 [database_name] < [script.sql]
```
