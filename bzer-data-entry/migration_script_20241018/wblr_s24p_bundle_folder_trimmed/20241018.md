# 1. Database backup
- Take database backup of `wblr_s24p` before running the `rename_folders.bat` script from `migration_script` folder positively.

## Note
- This backup is taken to prevent any data corruption in the database by running the script.
- So to restore the previous data in the database.

# 2. Folder backup
- Take all the **folders**(bundles) backup before running `rename_folders.bat` script positively.

## Note
- This backup is taken to prevent any corruption happen in the **directory** to the folders.
- So to restore the previous version.
