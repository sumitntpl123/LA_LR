Note : Must backup the database before executing the sql script.

Step 1: Execute the `DuplicateKhatian.sql` script for removed the dublicate records. To run this script follow the below steps:
1. Save the CSV file containing the bundle names associate to duplicate khatian in the `C:/` drive. The CSV file should have only one column with the bundle name.
2. Change and save the `csv` file name as `duplicate_khatian`.
3. Run the `DuplicateKhatian.sql` script in the command line.
```console
mysql -h [hostname] -u [username] -p --default-character-set=utf8mb4 [database_name] < [script.sql]
```
